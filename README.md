# beat-tracking-results
Results of the Audio Beat Tracking task (`<year>/<dataset>/<submission>.csv`: mir_eval beat metrics per file, `#avg` = dataset mean).

2026: computed with `scripts/main_beat_tracking.py`; identical to mirex-evaluation `audio_beat_detection` (checked 2026-10-15). JSIR: 260 recordings, scored per valid segment.
Yamaha (YAMAHA_Balanced 239, YAMAHA_JPop 250): outputs exported by Yamaha, scored by the organizers with the same script.
